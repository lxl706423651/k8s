# 容量平衡下界：迭代研究结果（2026-09-28）

本轮离线研究、规模试验和独立证书审计全部完成。输入仍只有物理CPU/内存预算与节点—LAN拓扑。最重要的新结果是：**1078节点的最优成本区间从[2,55]收紧为[32,55]**。4954节点为[22,91]，7001节点为[29,118]。下界来自可逐项验证的整数路径证书；上界来自本轮重新审计的历史可行映射。没有把下界提高说成分区算法成本下降，也没有运行新的VM/Crescent性能比较。

## 1. 模型与本轮解决的问题

共同资源包政策、精确最大额度z*及原LAN成本S=Σ_e(λ_e−1)保持不变。原模型确定主机节点容量L，却缺乏利用这些容量的强成本下界。此前两点最小割下界在1078节点只有2。本轮研究的是：**哪些跨主机连接是容量限制下不可避免的，以及如何用独立证书证明这一点？**

在证明中人为选择终端节点对并为它们寻找路径，仅是数学构造；没有请求或输入实际业务流量、速率、CPU剖析或额外物理节点。

## 2. 容量感知的路径拥挤证书

对一个含n个证明终端的连通子图，主机最多容纳L_h个终端。将终端尽量集中于容量最大的主机，再依次填充，得到计数a_h。该计数向量使Σa_h²最大，故任意可行映射至少分开

D(n,L)=(n²−Σ_h a_h²)/2

个无序终端对。证明理由是任意r个主机所容纳的终端数不超过最大的r个容量之和，因此贪心计数向量主序支配其他计数向量；平方和是凸对称函数。断开的连通分量分别计算D再相加，作为保守保证。

为每个终端对选择一条拓扑路径。设LAN e被l_e条路径经过，B=max_e l_e。每对位于不同主机的终端，其路径至少经过一个跨主机LAN。于是

D ≤ Σ_{e为跨主机LAN} l_e ≤ B·跨主机LAN数 ≤ B·S，

因此S≥ceil(D/B)。本实现保存每个源点的路径树，逐一核对树的原始关联边、无环性、目标覆盖和整数拥挤量；浮点最短路程序只负责产生候选路径。

还可组合不同终端集合：第j份证书有保证D_j和原LAN负载l_ej，选择非负整数w_j后，

S ≥ ceil(Σ_j w_j D_j / max_e Σ_j w_j l_ej)。

LP只建议组合权重，真正发布的比值全部用整数与有理数重算；不依赖LP状态、近似目标或数值容差来证明下界。

## 3. 根据反馈完成的迭代

1. 全节点对、初始广度优先路径：1078下界3；四轮重新加权，单轮证书达到12。
2. 组合16轮证书：下界27。又加16轮由LP瓶颈价格指导的路径，仍为27。
3. 为解释停滞，增加整数距离证书。LAN长度ℓ与满足所有边距离不等式的势函数给出总距离P；任何全节点对路径的最大拥挤B≥P/Σℓ。因此此类下界的整数上限为ceil(DΣℓ/P)。1078该上限恰为27，证明继续优化同一种全节点对构造也无法超过27；**不是证明原分区最优值为27**。
4. 改选较大的连通证明子结构。首次连同瓶颈LAN删除，三阶段最好26，属于负结果。修正研究策略为仅选择终端、保留全部原LAN在终端上的限制，最好28。两种都合法，但删除LAN会丢失可用的证明信息。
5. 对第一个诱导子图追加32轮、更新系数由2改为0.5，最好30。最后将不同终端集合的全部144份路径证书映射回原LAN后联合组合，得到**32**，超过全节点对方法已证明的上限27。

所有证明子问题都沿用**原始1078节点任务导出的容量261/294/523**。被排除的证明终端仍留在原分区问题内；没有重新计算更有利的共同额度。每次调整均保存登记、原始输出及负结果，不属于预先独立留出的算法比较。

## 5. 正确性与执行状态

- 原始路径方法在40个小图的10464个可行分区上验证；容量集中计数另外穷举核对。
- 快速树检查与原始检查在30个小图、已保存1078路径上完全一致；修复开发阶段的孤立节点空索引处理后通过。
- 30个小图验证距离上限、整数组合和子图限制；另30个小图专门验证不同终端集合组合。篡改路径根或距离势均被拒绝。
- 15组计算结果已独立重读，验证274832棵源路径树、全部相关源码/输入哈希、整数负载与组合比值。初始慢版四轮与快速版对应证书逐数组一致。
- 原始完整图方法上限27、终端混合下界32均重算通过；所有上界映射重审，满足下界≤上界。
- 没有VM配置变更、没有在线运行、没有遗留实验进程。新代码编译检查及报告链接检查见最终完成记录。

## 6. 研究价值与边界

本轮得到的不只是一个更大的下界数字，而是一个可反驳、可检验的机制：全节点对构造受到局部瓶颈限制；距离证书识别了该方法的上限；改变证明终端并组合不同容量保证，实际越过了这一上限。模型因此增加了“可行解—不可避免成本—证据差距”的完整评估层。

多商品流下界与平衡划分本身已有长期研究，见[Sensen的原始论文/学位论文](https://digital.ub.uni-paderborn.de/hsmig/content/titleinfo/3057)及[spreading metrics原论文说明](https://research.ibm.com/publications/fast-approximate-graph-partitioning-algorithms)。本项目不把最大流、路径拥挤、LP或列生成思路称作原创。当前实现只用这些工具构造可核验的超图LAN成本证据，尚未完成系统性新颖性论证。

对Crescent的边界仍与前轮一致：这是受限输入的容量与分区成本研究，不是完整平台性能对比。默认分区器保持不变。本轮值得保留的方向是**容量保证不同的终端集合如何选择和组合**；应优先把已验证的32下界机制推广到其他拓扑，而非继续无目的增加同类路径轮数。
