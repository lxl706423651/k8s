# 容量—拓扑分区研究：2026-09-28 完成结果

本轮全部离线实验与独立审计已完成，没有部署新的 VM 工作负载。结论：问题现在有清晰的可证明边界和可验证目标，但当前算法创新与独立数据证据仍不足以宣称超过完整 Crescent 系统。最有价值的结果是识别了资源比例错配、图表示失真和启发式搜索误差三个不同来源，而不是单纯扩大拓扑。

## 1. 问题定义及可证明部分

只输入 N 个虚拟节点及 LAN 成员集合，以及物理主机 CPU/内存容量 Ck、Mk。无节点需求画像、流量、每包 CPU 时间或额外计算节点输入。采用明确的公平政策：每个虚拟节点获得相同资源包 (z·ΣC/N, z·ΣM/N)。这是分配政策，不是对应用需求的估计。

记 ak=Ck/ΣC，bk=Mk/ΣM，qk=N·min(ak,bk)，nk 为分配到主机 k 的节点数。原 CPU/内存约束等价于 nk≤floor(qk/z)，Σnk=N。因此该固定包政策下两维约束退化为标量计数容量，不能把它包装成新的通用多资源分区算法。

精确最大额度为 z*=max{z:Σk min(N,floor(qk/z))≥N}，只需在 qk/j (1≤j≤N) 的有限断点上搜索。给定 z，每主机可用整数槽位之和不少于 N 是必要且充分条件；由此得到额度的精确证书，与拓扑无关。

连续上界 z_relax=Σmin(ak,bk)=1−½Σ|ak−bk|。这解释了即使总 CPU/内存不变，分布比例错配仍会损失共同额度。三组容量均为 72 CPU、128 GiB：aligned=(18/32,18/32,36/64)，heterogeneous=(16/32,24/32,32/64)，misaligned=(16/64,24/32,32/32)。连续上界分别为 1、11/12、13/18；整数证书接近这些界限。该恒等式作为本问题的解释性推导，不宣称数学新颖性。

令 Lk=floor(qk/z*)，t=max_{Lk<N} qk/(Lk+1)。在 t<z≤z* 内所有整数槽位不变，因此真正的最优拓扑成本也不可能因放宽这段额度而改变。若启发式在此范围返回更低成本，改善来自搜索，而不是公平性代价。新增精确 Fraction 实现通过了 60 个小规模随机实例的所有计数分配穷举核对。

在最大额度下最小化 S=Σe(|hosts(e)|−1)。在已验证的 VLAN+macvlan 后端，父接口数 A=|E|+S；这是可观测结构成本，不是吞吐、时延或需求预测。默认目标为先最大化 z，再最小化 S。放宽额度只输出供决策的候选前沿，不自动降低默认公平目标。

## 2. 规模选择与实验设计

1078/1065 LAN 用于较小真实拓扑及精确求解尝试；4954/4763 LAN、7001/6708 LAN 用于离线扩展和表示失真压力测试。4954/7001 超出当前单 VLAN ID 空间和部分 worker 的 maxPods=2000，直接增大 VM CPU/内存不能解决，所以没有把离线可行性冒充部署成功，也没有为本轮盲目扩容 VM。

三个规模不是独立数据集：1078 的节点全部包含在4954中；4954 与7001共享4122节点（83.21%）。本轮只能说明同一拓扑族上的扩展性。前轮214/3083的实际部署证据见[前轮完成报告](RESEARCH_RESULT_FINAL_20260927.md)，不能替代本轮规模的在线实验。

冻结3规模×3容量布局×8搜索额度×3种子，共216次原生求解；另做27次普通团展开与27次归一化团展开。使用同一 KaHyPar 配置、严格容量和配对种子，比较表示方式；这是等调用次数对照，不是等运行时间。共270个映射独立重算原始 LAN 成本与有理数实际额度，全部通过。

## 4. 强对照改变了什么判断

原生超图对普通团展开27组全部更低，但不能据此认定表示方法全面优越：普通团展开将一个 m 成员 LAN 展成 m(m−1)/2 条边，可能放大大 LAN。追加每 LAN 总权重归一化为1的团展开后，原生超图仅17胜、10负。归一化版本按100000缩放取整，审计考虑了整数误差界。

即使归一化，图目标也不等于LAN跨度：6成员LAN按1/5和3/3跨两个主机，S都为1，而图割分别5和9，归一化后仍不同。因此强对照能削弱“只是权重缩放”的解释，却不能自动证明所有拓扑都应使用某一个求解表示。

随后用新种子2027/2539/3049，在异构布局下做18次15秒预算实验：原生多次搜索与“加入一次归一化图候选后继续原生搜索”配对。转换、求解、审计均计时，超时返回不得入选；C++调用允许结束，所以15秒是选择截止，不是硬进程超时。独立审计全部1072次调用及18个最终输出。

组合策略9组中1胜、8平、0负；唯一改善为7001种子2539的162→153，其余完全相同。当前证据不足以改变默认策略，保留 native；组合策略只是可选探索接口。新随机种子不构成独立拓扑验证。

1078严格与95%额度的MILP各运行120秒，均超时，返回S813/815，下界约0，未提供有用成本证书。保留该负结果，不能称S55为最优；精确成立的是容量证书，不是大规模分区成本证书。

## 5. 与 Crescent 的可比范围

使用冻结的 Crescent 分区参考实现，3规模×3统一容量×3种子共27次，逐一尝试主机排列并在3种容量布局下审计81个映射。只比较受限输入下的分区适配，不是原论文全部系统。下表基线选取所扫描候选中最大实际共同额度，额度相同时选较低S；新方法列候选池的最大额度解。

|节点数|本模型 z|本模型 S|Crescent适配 z|Crescent适配 S|
|---|---:|---:|---:|---:|
|1078|0.916082|55|0.669150|360|
|4954|0.916644|91|0.667205|2199|
|7001|0.916511|118|0.666857|2897|

本候选在这次有限扫描中同时有更高额度和更低S，但两侧不是同额度或同时间预算的算法对照，不能把数值差异全部归因于新算法。容量模型改变了问题假设，原论文另有完整系统优化。强算法对照应以前述相同容量、相同后端的表示消融与等预算实验为准。

## 6. 科研判断与下一步优先级

目前是定义良好、具有解释性和可复核实验的问题；尚不足以声称论文级新颖算法或全面超过 Crescent。合理的研究叙述是“需求未知时的固定资源包可达性及 LAN 实现成本”，明确不解决未知流量性能预测。其可检验机制是容量比例错配、整数槽位断点、实际额度前沿与部署成本恒等式。

下一阶段应优先引入来源独立、LAN大小分布不同的拓扑，对原生超图与归一化图做预先冻结的等预算检验；然后研究能利用整数槽位断点或LAN结构的局部改进，并以强基线验证增益。不能仅增加同源节点数或追加随机种子来弥补新颖性。若要4954/7001在线结论，应先单独改造可扩展网络标识/主网络后端，再做相同配置、重复且顺序平衡的部署实验；这一基础设施改造不应当被写成分区模型创新。
